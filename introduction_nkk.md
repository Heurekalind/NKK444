# Einführung

## Allgemein

Im Folgenden erfahren Sie welche Ansprüche Standortdaten in der Datenerfassung des Projekts  "Natürlicher Klimaschutz in Kommunen" erfüllen müssen.
Es ist erforderlich dass Geodaten sich einer Zuschusszusage, einer Maßnahme und einem Berichtszeitpunkt zuordnen lassen.
Die Datenerfassung unterscheidet sich je nach Art der Geodaten die erfasst werden.

## Punktreferenzierte Maßnahmen
Der Vereinfachte Prozess bei dem nur Geokoordinaten manuell in einer Excel erfasst werden können ist für folgende Maßnahmen anwendbar:

* Maßnahme B.2 – Straßenbaumpflanzung
* Maßnahme B.3 – Einzelbaumpflanzung (exklusive Sträucher, Hecken)
* Maßnahme B.4 – Standortoptimierung von Bestandsbäumen

Im Bereitgestellten Validator können Sie Ihre Excel hochladen, prüfen und automatisch eine georeferenzierte Datei zur Einreichung erstellen. 
Eine Anleitung dazu finden sie im Kapitel "Leitfaden zur Datenerhebung"

## Flächen- und Linienreferenzierte Maßnahmen

Für folgende Maßnahmen ist die Erfassung von Flächen oder Linien zur Standorterhebung notwendig:
Maßnahme A.3 – Aufwertung von Grünflächen
Maßnahme B.3 – Einzelpflanzung, Sträucher, Hecken
* Maßnahme C.1 – kleine Parkanlagen
* Maßnahme C.2 – Naturerfahrungsraum
* Maßnahme C.3 – urbane Waldgärten
* Maßnahme C.4 – urbane Wälder
* Maßnahme C.5 – Renaturierung von Kleingewässern
* Maßnahme D.2 – Entsiegelungsmaßnahme

Sollten Sie keine Vorkenntnisse zum Erfassen von Geodaten haben, finden Sie eine 
Anleitung im "Leitfaden zur Datenerhebung".
