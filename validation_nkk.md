# Datenvalidator
Sie sind verpflichtet, Ihre Daten vor der Übermittlung an die KfW zu validieren.  
Dazu stellen wir Ihnen den Online-Validator bereit den Sie im Browser nutzen können.
Sie können Excel und GeoJSON Dateien hochladen und prüfen.  
Zum einen erhalten Sie einen Hinweis falls der eingereichte Datensatz nicht den Vorgaben entspricht und an welcher Stelle nachgebessert werden muss.
Zum anderen werden die von Ihnen angegebenen Standort in der Karte visualisiert und Sie können diese auf Plausibilität und Vollständigkeit prüfen.  
Fehler sollten in der Originaldatei mithilfe von Excel oder GIS-Software korrigiert werden.
Nach der Korrektur können Sie ihre Datei erneut überprüfen.

Wenn alle Anforderungen erfüllt sind, können Sie sich automatisch einen Email-Entwurf zur Einreichung erstellen lassen.

Wichtig:
Bitte verwenden Sie für die Validierung die aktuellste Excel-Vorlage; ältere Versionen werden vom Validator nicht akzeptiert.  
Stellen Sie sicher, dass Sie die aktuellste validierte (und gültige) Version der Daten an die E-Mail anhängen.

Hinweis:
Falls Sie ihre Daten manuell ohne den Validator prüfen möchten können Sie dies mit Hilfe unseren in Anhang 2 beschriebenen Anforderungen abgleichen.
